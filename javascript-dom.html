What is JavaScript and its relationship to HTML and CSS?

The typical analogy to explain the three is the makeup of a house. HTML is the basic structure of a website. Within the house HTML is the foundations, frame, walls and roof of the building. It dictates how large the house is, what you actually interact with on the outside and in. CSS is the design of a website. It changes the house’s looks and decoration, what colour the walls are painted, how the rooms are laid out and all other such things. It dictates how the basic frame provided by HTML is made to look. Javascript is the functionality of a website. In the house metaphor you could think of it as all the wiring, plumbing and functions that you need to interact with different parts of the house. CSS might choose where a window is, but javascript acts as the hinges and latch that allow someone to open it.

What are control flow and loops?

Javascript control flow is the order in which javascript chooses to do things. Think of it as a written schedule for a day's events. This is the schedule:

  • 6:00am - Wake up
  • 9:00am - Go to doctors appointment
  • 1:00pm - Brush teeth
  • 1:30pm - Dentist appointment

By default the order you go through scheduled events in the schedule is top to bottom. Javascript is written in a similar vertical format and just like the schedule by default it will enact any events in the script from top to bottom. There are a number of ways to change this however. For example, what if the doctor gives you a prescription and you need to add into the schedule (or control flow) a trip to the pharmacy to pick it up? One common way to do this in javascript is If and Else statements, which are called conditionals. They work mostly how you’d expect, for the schedule example If you are given a prescription then you should take a trip to the pharmacy, Else (otherwise) carry on with your schedule. There are a number of other different ways if else statements can be used, often involving mathematical equations, if a given value is greater than twenty, enact this line of code, if it’s lower, enact another one. All of these can disrupt the order of the control flow in different ways based on different input values. Another important way to interact with and interrupt control flow is using loops (also called For loops). Right before our scheduled trip to the dentist at 1:30 we want to brush our teeth. This is in the schedule at 1:00 and by default it will be enacted once before moving on to the next item. Say we want to brush our teeth extra times before the dentist, we could use a loop on the brush teeth schedule item to loop through it as many times as we want. What is the DOM? How might you interact with it?

When you open a website in a browser it displays the house discussed in the first section of this blog post. The website you see is the combined structure, design and function of HTML, CSS and Javascript. The tool that the browser uses to view and parse the way these three are structured is called the DOM. DOM is an acronym for Document Object Model and it views and displays the written code of a website (the document / document object). All the small parts that make up the DOM are called nodes. These nodes include all of the HTML elements, text and all of the different parts of a website. You can view the DOM in any browser by right clicking and using the inspect function that opens up devtools, which allows you to access and change the DOM in various ways, changing the code of a website freely, altering text on the page or deleting/changing elements entirely.

What are objects and arrays? How would you access data from them?

Arrays and objects are both used to contain multiple elements but are fundamentally different in a few ways. An array contains elements in a specific numerical order, making it great for ordered lists or any use case where the specific order of items is needed. Objects do not have any specific order. They are better used to contain something with multiple properties, displaying the different parts of an object. A typical example of this would be a person object that contains their name, height, age, etc. If you wanted to make a list of people then an array would be the more suitable method. Aside from syntax this is the fundamental difference that matters when it comes to accessing data from them. Because arrays have a numerical index the data inside can be accessed with its correlating index number. These arrays count upwards from 0, so to access the first item in an array you would need to enter the value of 0 into your code. Note the square brackets [ ] used in an array's syntax.

What are functions and how are they useful?

A Javascript event is an action or occurrence on your webpage that is triggered by the written code. Functions in Javascript are used to make an instance of an event easily repeatable throughout your code. Without functions you would have to individually alter each event in every instance of its use in your code, which is completely unrealistic and time consuming for any project other than maybe an extremely small one.
